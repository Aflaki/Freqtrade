# راهنمای نصب روی سرور دبیان

## پیش‌نیازها
- سرور **Debian 12** (یا جدیدتر) با دسترسی root.
- سرور **خارج از ایران** باشد. تلگرام و صرافی‌هایی مثل بایننس و بای‌بیت به IP ایران سرویس نمی‌دهند.
- دامنه اختیاری است. اگر دامنه ندارید، اسکریپت خودکار آدرس رایگان `IP.sslip.io` را با HTTPS واقعی می‌سازد.
- پورت‌های **80 و 443** باید آزاد باشند. پورت دیگری (مثل 1200) ندهید.

## ۱) دامنه را به سرور وصل کنید
در پنل DNS دامنه یک رکورد **A** بسازید:

| Type | Name | Value |
|---|---|---|
| A | panel | IP سرور |

چند دقیقه صبر کنید.

## ۲) به سرور وصل شوید
در ویندوز PowerShell، و در مک و لینوکس Terminal را باز کنید:
```bash
ssh root@IP_SERVER
```
اگر با کاربر دیگری وارد شدید، با `su -` به root بروید.

## ۳) نصب (یک دستور)
```bash
apt update && apt install -y curl
```
```bash
curl -fsSLO https://raw.githubusercontent.com/Aflaki/Freqtrade/main/deploy/install.sh
```
```bash
bash install.sh panel.example.com
```
بدون دامنه، فقط:
```bash
bash install.sh
```
در پایان نصب، ایمیل و رمز ادمین را می‌پرسد. اسکریپت این کارها را خودکار انجام می‌دهد:
- نصب پایتون و Caddy
- گرفتن گواهی HTTPS
- ساختن سرویس که بعد از ری‌استارت سرور خودش بالا می‌آید
- بکاپ روزانه

## ۴) تنظیمات از داخل سایت
`https://panel.example.com` را باز کنید و با حساب ادمین وارد شوید.

1. **ساخت ربات تلگرام:**
   - در تلگرام به `@BotFather` پیام بدهید و `/newbot` را بفرستید.
   - یک اسم و یک یوزرنیم که با `bot` تمام شود بدهید.
   - توکنی که می‌دهد را در **مدیریت ← تنظیمات ← ربات تلگرام** بگذارید.
2. در **تنظیمات و تلگرام** روی «اتصال تلگرام» بزنید و در تلگرام Start را بزنید.
3. در **مدیریت ← تنظیمات ← فرمول**، ارزهای مجاز را دقیقاً مثل `pair_whitelist` ربات Freqtrade وارد کنید، و صرافی‌ها و فرمول را هم تنظیم کنید.

## ۵) وصل کردن ربات‌های Freqtrade (یک یا چند ربات)
هر ربات Freqtrade در سایت یک «ربات» جدا با **آدرس وب‌هوک مخصوص خودش** است. از روی همین آدرس معلوم می‌شود هر پیام از کدام ربات آمده.

1. **مدیریت ← وضعیت ربات ← افزودن ربات**. برای چند ربات، از «افزودن گروهی» استفاده کنید؛ هر خط یکی:
   ```
   نام | http://IP:PORT | username | password
   ```
   - آدرس API همان `listen_ip_address:listen_port` بخش `api_server` همان ربات است.
   - اگر API را بدهید، استراتژی، صرافی و whitelist خودکار خوانده می‌شود.
2. روی نام ربات بزنید و **آدرس وب‌هوک** آن را کپی کنید.
3. در کانفیگ **همان** Freqtrade، بلوک `webhook` را از [`freqtrade/webhook-config.json`](../freqtrade/webhook-config.json) بگذارید و `url` را همان آدرس کنید. ربات را ری‌استارت کنید.
4. برای هر ربات این تنظیم‌ها را دارید:
   - فعال یا غیرفعال
   - کپی شدن سیگنال‌ها روی سبد کاربران
   - نمایش در سایت

**کاربران** در فرم سبدشان انتخاب می‌کنند کدام ربات‌ها را دنبال کنند. آمار هر ربات کنار اسمش نمایش داده می‌شود.

**FreqUI شما دست نمی‌خورد.** سایت فقط با همان نام کاربری و رمز API می‌خواند و بخش `api_server` را تغییر نمی‌دهد.

## ۶) تست
یک سبد برای خودتان بسازید و **آزمایشی (Dry-run)** را روشن بگذارید. با اولین سیگنال باید پیام تلگرام بیاید.

## دستورهای کاربردی

| کار | دستور |
|---|---|
| وضعیت سرویس | `systemctl status signal-relay` |
| لاگ زنده | `journalctl -u signal-relay -f` |
| ری‌استارت | `systemctl restart signal-relay` |
| آپدیت به آخرین نسخه | `bash /opt/signal-relay/deploy/update.sh` |
| فراموشی رمز ادمین | `cd /opt/signal-relay && runuser -u relay -- env DATA_DIR=/opt/signal-relay/data venv/bin/python -m app.cli reset-password EMAIL NEWPASS` |

## بکاپ — خیلی مهم
- بکاپ روزانه در `/var/backups/signal-relay` ذخیره می‌شود.
- فایل `/opt/signal-relay/data/secrets.json` را **یک بار روی کامپیوتر خودتان هم کپی کنید**. بدون آن، کلیدهای API کاربرها قابل باز شدن نیستند. دستور کپی (روی کامپیوتر خودتان اجرا کنید):
  ```bash
  scp root@IP_SERVER:/opt/signal-relay/data/secrets.json .
  ```

## اگر سایت باز نشد
- پورت‌های **80 و 443** باید در فایروال پنل دیتاسنتر باز باشند.
- اگر `ufw` روی سرور فعال است:
  ```bash
  ufw allow 80,443/tcp
  ```
- وضعیت HTTPS:
  ```bash
  journalctl -u caddy -n 50
  ```
  معمولاً مشکل این است که DNS هنوز به سرور اشاره نمی‌کند.
